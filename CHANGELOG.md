# История изменений (Changelog)

Все заметные изменения в проекте ReVoice документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), и проект придерживается [Семантического версионирования](https://semver.org/lang/ru/).

## [0.1.0] - 2026-09-29

### Добавлено
- **Нативное десктоп-приложение ReVoice** на базе Tauri 2, React 18, TypeScript и Tailwind CSS.
- **Движок синтеза речи Qwen3-TTS** с поддержкой моделей 0.6B и 1.7B, оффлоадом на 4 ГБ VRAM и защитой от meta-тензоров.
- **Движок синтеза речи Fish Speech 1.5** с потокобезопасной очередью DualAR, декодером Firefly VQGAN и студийной дискретизацией 44.1 кГц.
- **Режим «Книги» (Audiobook / M4B)**:
  - Парсинг текстовых файлов и Markdown по главам.
  - Автоматическая разметка пауз и эмоций под художественное чтение.
  - Синтез и сборка нативного файла `.m4b` с метаданными оглавления для мобильных плееров через встроенный `imageio-ffmpeg`.
- **Управление голосовыми профилями**:
  - Создание, редактирование и удаление голосов.
  - Автоматическая QA-валидация эталонных аудиозаписей (проверка длительности 3–30 сек, фильтрация тишины по RMS, контроль частоты дискретизации).
- **Экран управления моделями**:
  - Мониторинг дискового статуса и загрузки в память.
  - Фоновое скачивание с проверкой целостности файлов и поддержкой докачки.
  - Возможность привязки локальных путей к уже скачанным весам без дублирования на диске.
  - Перенос рабочей директории моделей с автомиграцией.
  - Кнопка принудительной выгрузки всех моделей из VRAM.
- **Глобальный системный хоткей** `Ctrl+Shift+V` для мгновенного озвучивания текста из буфера обмена.
- **Системный трей Windows** со сворачиванием/разворачиванием окна и быстрым выходом.
- **Нативный установщик Windows** в формате MSI с русской локализацией интерфейса инсталлятора.
- **Автоматизированный тестовый набор** (30 тестов), покрывающий валидацию сэмплов, нарезку текста, эффекты, API моделей и инспекцию сигнатур нейросетевых движков.
